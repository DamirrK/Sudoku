SUDOKU - offline app
By Offline is King

Put these files on any free static host that uses https (GitHub Pages works well),
open the address in Chrome on your phone once, then use Chrome's menu > "Install app"
(or "Add to Home screen"). After that it runs fully offline.

Updating: upload the new index.html, and change VERSION in sw.js (e.g. sudoku-v6).
The phone picks up the update the next time it opens the app with a connection.
